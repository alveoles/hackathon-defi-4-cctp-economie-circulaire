# Défi 4 — Des clauses CCTP d'économie circulaire

> Hackathon Alvéoles × Epitech × AGYRE — mercredi 2 décembre, TechSud (Saint-Pierre)

## Le contexte

AGYRE dispose d'une application en ligne qui fait du **match-making** entre :

- les données d'un **diagnostic PEMD** (grille démoclés) : les déchets et gisements de matériaux d'une opération ;
- une **base de filières de gestion des déchets**.

Aujourd'hui, l'application sort la liste des **filières locales** capables de traiter chaque déchet ou gisement, selon sa typologie et la localisation de l'opération.

## Le défi

Construire une **brique complémentaire** qui poursuit l'accompagnement en économie circulaire : à partir des données de sortie de l'application, proposer à l'utilisateur des **clauses techniques de type CCTP**, issues d'une base de clauses (aujourd'hui externe à l'application), pour l'aider à rédiger son **CCTP déconstruction** et ses clauses d'économie circulaire. Exemple : la dépose soignée des matériaux les plus qualitatifs.

Les clauses retenues doivent pouvoir être intégrées ensuite au dossier de conception.

## Livrable attendu

- Une brique qui tourne : données de sortie → clauses CCTP proposées
- Une démo live
- Un README qui explique comment lancer le projet
